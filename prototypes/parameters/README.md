## 这个复刻"真"在哪

不是凭记忆重写,而是**逆向原版 SWF** 把每个数字挖出来:

1. `CWS` = zlib 压缩的 SWF → 解压 → 解析 tag → 定位 `DoABC`(AS3 字节码)。
2. **自建 AVM2 反汇编器**(Python),解出全部 243 个方法体,常量池 + 符号栈重建赋值/表达式。
3. **多智能体工作流**:16 个类各一个 agent 抽取数值,再各一个 agent **逐条指令对抗验证**(附偏移量佐证)。
4. 把验证过的公式灌进 `index.html`,逐条对应字节码(代码注释标了出处)。

核心还原(全部有据):
- `m = 条宽 × 条高` 决定一切;敌人 HP = 条宽;Boss HP=240(需 `atk>200` 破防);True Boss HP=9999
- `exp_max = 100+(lv−1)²`;逐帧再生四公式(@30fps);升级全回血送 3 点
- 受击 `int(dmg×0.5×(1−def/300))`,死亡归零攻防
- 武器/防具价格公式(恒定)、修复/加上限/买钥匙/买点数按钮真实价与递增
- 老虎机三轮真实符号分布与派奖($$$=1600 / @@@=200xp / 777=15540 / ***=9600)
- 属性点系统(赚点→加点按钮花点)、里程碑 bonus、连击(COMBO_MAX=120, 窗口 45 帧)
