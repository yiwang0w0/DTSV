# 远星函馆 — 最小可用世界观

> 本文档是游戏内 lore 的唯一权威参考。所有 item/npc/event/ending 的文案都从这里推导。
> 更新时间：2026-05-10

---

## 一、玩家第一眼看到的东西

在黑洞轨道上，有一段残破的巨型环结构。

它本该彻底坍缩进视界线，但现在以一种不自然的姿态悬停着：一部分环面断裂、扭曲，另一部分被某种半透明的"泡泡"强行咬住、包覆，像伤口上结了一层诡异的疤。环面上还有零星的灯光和结构在缓慢闪烁，看起来既像在自我修复，又像在被什么东西慢慢"吃掉"。

这就是 **17号异常段**（也叫 Ω-段核心区）。它是远星函馆平台在一次失衡事故中留下的残骸。

### 为什么没掉进黑洞？

泡泡的壳体反向包覆了断裂面 + Ω-段的自适应张力在持续拉扯。两股力刚好抵消了引力坍缩，让整个结构维持在一种"半塌陷却又稳定扭曲"的诡异平衡里。没人知道这个平衡还能维持多久。

## 三、Lore 发现路径（分层设计）

### 早期（外环维护廊 → 锚点走廊）

玩家只知道：自己是"引导者"，被派到一段残破的环形结构上执行任务。

能捡到的东西和看到的文本：
- **结构碎片**：从环面上脱落的金属片，上面有模糊的编号
- **环段部件**：还能用的结构零件，可以修复东西或作为撤离消耗
- **锚点稳定协议**：一份残缺的技术文档碎片，只看得出"锚点-β""稳定""结构失衡"几个词
- **结构修复包 / 认知稳定剂**：标准补给品，没有特别的 lore

事件文本风格：简短、技术性、不解释背景。
> "接口已松动——你拆下了一块完好的环段部件。"
> "残存的锚点稳定协议在你指尖静电中显形。"

### 中期（伊甸港残墟 → 剪切界面缓冲带）

开始接触非结构性的信息：

- **击杀残响实体**：死亡时闪过碎片化的画面——泡泡里曾经有什么东西在活动
- **遇到伪装体**：这些东西在模仿引导者的编号，说明有别的东西也想进入这个环
- **与共生体交易**：用环段部件换 Ω物质，共生体会低频发出片段：  
  "……平台不是用来住的……是用来造东西的……"
- **与观察者交易**：用结构碎片换深界情报，观察者的镜面表面会回放你之前的行动
- **语言压缩算法**：一份无法完整解码的数据，标注来源是"泡泡内部"
- **泡层壳体裂解事件**：泡泡的外壳裂开了，残响实体从里面涌出来——泡泡里确实有东西

玩家在这个阶段开始好奇：
> "泡泡里到底有什么？"
> "这个环原来是用来干什么的？"
> "为什么有东西在伪装成引导者？"

### 后期（Ω-段核心接口）

进入最深处，信息密度骤升：

- **Ω物质**：不是普通物质，是"在被重新排列的数据"——暗示环结构在进行某种计算
- **共构扰动样本**：Ω-段核心的采样，标注"泡泡与平台在此处共构"——两者不是简单的粘合
- **Ω-段脉冲事件**：进入时受到伤害 + 看到闪回——自己可能不是第一次来这里
- **深界情报（观察者交易）**：标记了一条"深界路径"，暗示环结构之外还有更深的层

### 隐藏线（结局触发）

集齐足够材料/满足条件后，触发四种结局：

| 结局 | 触发条件概要 | 玩家感受 |
|------|-------------|---------|
| **崩解** | 污染爆表 + 多次撤离失败 | 环终于撑不住了，掉进黑洞 |
| **清算** | 大量击杀实体 + 碎片收集少 | 平台判定异常段没有保留价值，强制隔离 |
| **合流** | 与非敌对实体充分交流 + 污染受控 | 泡泡里的东西和平台达成共存 |
| **探索** | 多次深入 Ω-段 + 提取足够 Ω物质 | 发现环结构之外还有更深的路径 |

## 五、文案风格指南

1. **不解释，只描述**：让玩家自己拼。"泡泡壳体出现了裂缝"比"泡层文明容器的保护壳体因结构失衡而破裂"好。
2. **泡泡不叫泡层**：游戏里统一叫"泡泡"，玩家不需要知道它的学名。
3. **引导者不解释**：玩家就是引导者，不需要解释"PI引导者协议"是什么。
4. **短句 > 长句**：事件文本控制在一两句话以内。
5. **技术词零星出现**：偶尔出现"锚点-β""D-8821""Echo-γ"这类编号，不解释，制造"这里曾经有一个完整系统"的感觉。
6. **后期才用"文明"这个词**：早期和中期完全不提文明、纪元、实验等概念。
