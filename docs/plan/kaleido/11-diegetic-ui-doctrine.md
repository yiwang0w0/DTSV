# KALEIDO · 11 Diegetic UI 教义(2026-07-22 · Kanata 拍板 · 长期铁律)

> **UI 不是元层的界面,是世界内的物件与能力。** 它可以被发现、被获得、被夺走。玩家探索的对象不只是地图,还有**系统本身**。
> 本文件 = 长期设计铁律,**所有未来机制都按此设计**。取代旧「渐进披露 = 系统主动解锁并教学」的范式(05 的 ui_unlocks 是其实现基座,语义按本文件重划)。

## 1. 三条法则

### 法则一 · 功能常在,观测要争取
**机制永远在运行,与玩家是否看见无关。** UI 只是观测窗口,不是功能开关。
- 体力一直在消耗 —— 不管玩家有没有点开那个条。
- 设施损毁度、武器磨损度一直在累积 —— 玩家发现了才有读数,没发现就只能靠感觉。
- **玩家没发现 ≠ 机制不存在**。

### 法则二 · UI 由世界内动作获得,而非系统授予
**不是系统在恰当时机"解锁"给你,是你在世界里做了一个动作,世界因此改变,UI 随之出现。**
- 「开关」范式(Kanata 原例):墙上有个灯泡开关 —— **玩家不按,房间就不亮**;而玩家得**自己想到**去按文字板上那个开关。UI 不是奖励,是**你操作世界的结果**。
- 武器改装 / 模式切换的界面:**默认隐藏**,要玩家自己探索到。
- ⟹ **隐蔽度是设计参数**:提示从「下划线」逐步收到「只靠措辞与位置暗示」。

### 法则三 · UI 可以失去
**UI 是资源,不是成就。** 单调递增是错的。
- 最终 boss 战:**夺走生命条** —— 玩家看不见自己还剩多少(制造压迫与恐惧)。
- 武器**炸膛/损坏** → 对应 UI 消失(后果的可视化)。
- 设施损毁 → 该设施提供的读数失效。
- ⟹ 必须区分三种「没有 UI」:**从未发现** / **曾有·被夺走** / **临时·被遮蔽**。三者的叙事与体验完全不同。

## 2. 叙事兜底(法则一的公平性保障)

**没有 UI 的玩家,靠叙事文字活着。**
- 体力降到 20% → 搜索后追加一行「你感觉有点累了」。**没点开体力条的玩家,只能靠这行字判断状态。**
- ⟹ 叙事在此**不是氛围,是替代仪表盘的信息通道**,承担功能性角色。
- ⟹ 叙事线索**同时是发现的诱饵**:持续暗示「你有个东西可以看」,防止「太隐蔽 = 永远发现不了 = 功能白做」。

**推论(文案口吻铁律)**:nar_line **不得使用「——已开放:XXX」这类系统宣告式**(替玩家宣布获得了功能 = 剧透探索)。改为**只描述世界与动作**,可交互词自然嵌在叙述里(玩家没注意就是普通叙述,注意到才发现能点)。

## 3. 架构冲突(必须先解决 · 🔧)

**现 `ui_unlocks` 是单调增的**(账号级持久化 · 全集覆盖 · 「天然幂等永不缩」),与**法则三(可失去)直接冲突**。需要重划语义:

| 层 | 内容 | 特性 |
|---|---|---|
| **机制层**(engine) | 体力/损毁/磨损/改装等**功能本身** | 永远运行,与 UI 状态**完全无关** |
| **观测层**(ui state) | `discovered`(已发现) / `suppressed`(临时遮蔽) / `lost`(被夺走) / 未发现 | **可增可减**,不再单调 |
| **叙事层**(nar) | 阈值线索 + 发现诱饵 + 失去时的叙述 | 观测层缺位时的替代通道 |

**待 🔧 评估**:①单调性怎么打破(三态模型 vs 解锁集 + 遮蔽集双层)②账号级持久(B1:veteran 满 UI)与「本 run 内被夺走」怎么共存 ③世界内触发器(开关类可交互点)的引擎表达 ④UI 剥夺的触发与恢复。

## 4. 前置缺口(机制层现状)

法则一要求「数据常在」,但 kaleido 引擎侧**目前缺这些数据机制**:
- **体力**:`staminaDelta` 被 `!isKaleidoRoom` 明确排除 —— **kaleido 现无体力经济**(Kanata 举的 20% 例子需先补此机制)。
- **设施损毁度 / 武器磨损度 / 武器改装与模式切换**:均**未实现**。
⟹ 这些是法则一的载体,需 ⚙️(数值/内容设计)+ 🔧(机制实现)排期。

## 6. 与既有决策的关系

- **B1(UI 即进度 = 一次性开场)仍成立**,但被本教义扩展:一次性的是「首次发现的惊艳」,而**探索系统本身**是长期玩法(法则二三让后续 run 仍有可发现物)。
- **B3(边界 = 仅现有循环)暂不变**:损毁/磨损/改装属新机制,排在现有循环全量之后。
