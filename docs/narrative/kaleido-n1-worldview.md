## 1. 一句话定位

**你是函馆上的一台维护单位。平台出了大事之后,系统把你调起,给了你一盏灯和一个「搜索」。内部的图,系统自己也没有;更深处那一段,系统自己都不敢看。**

## 3. 写作铁律(本轮新增 · 全部玩家可见文本适用)

**可读性 > 世界观展示。** 具体规则:

1. **专名预算制**:玩家前期可见文本**零发明名词**。「泡泡」除外(它本来就是日常词,这正是当年定它的理由)。同屏新专名 ≤1。
2. **名随物后**:任何专名必须在玩家**亲眼见过对应事物之后**才出现。π-段这个名字本身也是渐进披露的对象——前期玩家只会看到「深处」「那边」「没有图的那段」,某个中期节点才第一次看到系统写下「π」,这一刻本身就是奖励。
3. **日常词优先**:伤就是伤,不是「结构侵蚀」;找就是找,不是「翻检扇区」;门就是门,路就是路。系统腔靠**句式和标点**冷(短句/冒号/破折号),不靠词汇生僻。
4. **深埋不说**:六纪元 / MPF / 文明实验 / 监听 / 泡层学名——玩家一律接触不到。工程体视角是天然防倾倒机制:**系统不会对一台维修单位解释宇宙观**。玩家的困惑只许指向「这地方怎么了」,永远不指向「这些词什么意思」。
5. **双频道照旧**(宪法 6.4):机制信息(目标/数值/威胁)永远走结构化 UI,叙事文本永远不承载操作指令。
6. 编号点缀极俭省:偶尔一个磨损的编号(不解释)制造「这里曾有一个完整系统」的感觉,每关 ≤1 处。

## 4. UI 渐进的叙事身份(与玩法设计咬合点)

- 开局黑屏一钮 = 系统在收缩状态,接口是暗的 ≠ 教学隐藏。
- 每次 UI 解锁 = 系统对这台维护单位**多授一格权限**(封锁控制权的逐步下放)——解锁瞬间配一行系统短句(`nar_line`,由 📖 供稿,N3 交付)。
- 解锁次序的叙事骨架(候选,供玩法侧参考):搜索(听/找)→ 储物(拿)→ 修理/合成(造)→ 自卫(它先看见你)→ 地图残片(你开始有图)→ 深入许可(往没有图的地方去)。
- **首次战斗解锁必须安全上演**(能伤你的机制,其读数 UI 先于该机制首害出现——硬时序法则,报中控入规格)。

## 5. 双层制的玩家可见词

| 层 | 玩家可见叫法 | 内部/后期名 |
|---|---|---|
| 外层驻点(持久层) | 「驻点」 | 维护轨道(中后期可露) |

## 6. 与其它产品线的关系

- **小说**(拓荒时代之后·Ω-段):KALEIDO 是它的**史前史**——玩家在系统自己派出探针(PI-1,拓荒时代)之前就先走进了没有图的地方。两边字母隔离(π/Ω),互不踩雷;远期若要联动,游戏玩家的足迹可以成为小说里系统数据的来历。
- **多人线**(深界时代·维护态):时代不同、称呼不同(引导者 vs 工程体),天然区隔,零改动。
