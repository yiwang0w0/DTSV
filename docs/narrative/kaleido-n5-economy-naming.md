## 命名系统（两类后缀 · 一眼分清）

工程体的东西就两种,后缀即品类,玩家扫背包一眼分清:
- **「…件」= 装上就一直在的**（持久强化,占身位)。三件统一「加X / 扩容」,词根即"永久加某属性"。
- **「…剂」= 用一次就没的**（消耗,一次性)。词根带时效/爆发感,天然与"件"拉开永久 vs 临时。
- **材料 = 散件**（从散架的地方捡的碎东西,拼成件/剂)。纯物件名,零功能学名。

## 1. 持久强化件（run 内永久 · §2.1）

| 功能（⚙️） | **名** | 描述（背包·即用） |
|---|---|---|
| +2 atk | **加力件** | 装上，出手更重一点。 |
| +2 def | **加防件** | 装上，挨打时少疼一点。 |
| +15 maxHp（并补满 15） | **扩容件** | 把自己撑大一圈。往后能多撑几步。 |

- 三件 **加力 / 加防 / 扩容** 各锁一属性、互不串味:扫一列即知"这仨装上永久加属性",天然与临时的「撑住剂」拉开。「扩容」直指血量上限变大（非"更硬"),避免与「加防」抢防御心智。
- **⚠ 扩容件 = 买时间,不是买耐打**(🧭 语义订正 · 2026-07-22):在 step1 的**有效剩余拍数**锚点下(N7 §3.1),+15 maxHp = **+3.75 拍** ⟹ 它的收益是**多撑几步**,不是"更硬/更耐打"。描述已按此改(「往后能多撑几步」),后续所有涉及它的文案守同一口径。⚙️ 已定它**只走合成、不进基础掉落表**(时间是这条曲线唯一的货币)。

## 2. 消耗剂（一次性 · §2.2）

| 功能（⚙️） | **名** | 描述（背包·即用） |
|---|---|---|
| heal 30 | **修补剂** | 糊上，缝就合一阵。 |
| heal 60 | **大补剂** | 一大管。糊得更实。 |
| 一次性 +100% 本回合伤害（burst） | **顶力剂** | 把出力顶到头。这一下重，完了就泄。 |
| def +5 · 3 回合（buff） | **撑住剂** | 撑住几下。之后自己散。 |

- 恢复走「修补 / 补」（工程体"糊缝"不"疗伤"),大小靠「大」区分,均 ≤3 字。
- **顶力剂**（burst）与持久的**加力件**成"永久加力 / 一次顶力"对照;**撑住剂**（临时 def）「撑」字自带"用力一阵、会散",与永久**加防件**清晰对立——防御拆两件,靠词根+后缀双重区分。

## 3. 材料·散件（⚙️ 新增 kaleido 行 · §2.3/§4）

> ⚙️ 新起 kaleido 专属材料行对应现 id13-18 功能位,**具体几个 + 谁配谁以 ⚙️ 合成树合稿定**。以下 6 个为散件基名（全新·不继承旧词根·零第六纪元/技术专名）:

| 散件 | **名** | 描述（背包·即用） | 气质（供配方对齐） |
|---|---|---|---|
| — | **碎块** | 从散架的地方掉下来的。硬。 | 硬/结构 |
| — | **卡扣** | 能扣住两样东西。 | 连接/扣紧 |
| — | **线圈** | 缠了一圈的。 | 蓄劲/绷着 |
| — | **垫片** | 软的一片，夹在中间垫。 | 软/缓冲 |
| — | **管段** | 一截空心的。接得上。 | 通道/接续 |
| — | **芯子** | 最中间那颗。别的都绕着它。 | 核心/被围 |

- 全是散架平台上捡得到的**日常五金件**,无学名、无编号、无第六纪元词。合成时"碎块 + 卡扣 → 加力件"读起来像"拿零件拼东西",符合工程体。
- **深界情报 / 语言压缩算法 / 锚点稳定协议 等旧名 = kaleido 面绝迹**（⚙️ 新行不用这些词根)。
- **⚠ 材料↔id 位↔配方语义 = 📖+⚙️ 合稿对齐**(名池灵活可换位):散件的"气质"列供 ⚙️ 把语义相符的散件配到产物——软/缓冲（垫片）宜喂**撑住剂/减伤向**,蓄劲/绷着（线圈）宜喂**顶力剂/burst 向**,硬/连接（碎块/卡扣）喂**强化件**。避免"软垫拼出爆发一击"这类语义违和。具体配方在 ⚙️ 权限,📖 只标语义诉求。

## 4. 敌梯度描述谱系（T0-Tboss · 描述制非正名）

> 敌人名随物后（N4）:玩家看到的是**描述 + 指示代词**,不是名字。谱系 = seq1-5 已定的「那X」延续。正名待第 3 见 payoff（挂起⑦)。

| 档（⚙️ 09 §1） | 已定敌（07/N4） | 描述制引用（玩家面） | 该档描述（氛围·供变体扩写） |
|---|---|---|---|
| T0 微弱 | 那东西（id8·seq2） | 「那东西」/「小东西」 | 刚会动。慢，轻，先看见你也不一定扑。第一次让你知道：这里不止你一个。 |
| T1 轻·杂兵 | —（变体待补） | 「成群的那些」/「一小群」 | 成不了气候的小东西，一个不算什么——架不住它们凑数。多，但不难。 |
| T2 中 | 那家伙（id9·seq3 精英）· 那东西（id8·seq4） | 「那家伙」（讲路数的）/「那东西」（又是它） | 会还手，会挑你出手的空子。到这一档，得动脑子。 |
| T3 重·硬杂兵 | —（变体待补） | 「沉的那个」/「不好啃的」 | 皮厚，慢，但一下比先前的沉。耗得起你——就看你耗不耗得起它。 |
| Tboss | 黑里的那个（id10·seq5） | 「黑里的那个」/「一直在的」 | 比你先到，早很多。它不急。系统不往这儿看。 |

- **谱系一致**:全用「那X /…的那个 /…的那些」指示描述,冷、无正名,与 seq1-5 已定敌名同一支。
- **维度分层**:T0=第一个/单只（「那东西」),T1=成群/量（「成群的那些」,去与材料"碎块"撞车),T2=会还手/技（「那家伙」),T3=沉/重（「沉的那个」,"沉"覆盖厚+慢+一击很重三体感),Tboss=古老/唯一（「黑里的那个」)。
- **T1/T3 是变体档**（seq1-5 无固定关,待 ⚙️ 敌人变体池 + 🔧 seed 洗牌);本表给描述家族,具体变体逐个配文时沿用。
- **命名 payoff**:「那东西」（id8）已见 seq2/seq4 两次,第 3 见触发首次命名（挂起⑦·落点待 ⚙️/Kanata)——那一刻的名由 Kanata 钦定,在此之前全谱系保持描述制。

## 6. 综合改动（三镜头发散评审 → 收敛）

基线经背包日常度 / canon / 功能对齐 三镜头评审,采纳改动:
- **扩容件**（← 加厚件·**硬伤修**）:maxHp 却易读成"加护甲/减伤"、与加防抢心智——改直指"血量上限变大"。
- **加防件**（← 挡板件）:「挡板」是场景遮挡物非随身增益;改与加力/扩容成整列"加X件=永久加属性"。
- **顶力剂**（← 过载剂）:「过载」偏技术腔;改与「加力」成持久-爆发对照,「顶」扣描述"顶到头"。
- **撑住剂**（← 稳固剂）:「稳固」抽象易读成抗控;「撑住」自带临时感,与永久加防件拉开。
- **大补剂**（← 大修补剂）:原 4 字破 ≤3 字线;压短。
- **垫片**（← 垫料）:「料」不可数、破六材料"具体五金件"整齐;归队可数五金件。
- **线圈**去描述"通着"电气暗示;**芯子**补辨识描述（"最中间那颗，别的都绕着它"）。
- **材料↔配方语义 co-align 注记**（§3):软/缓冲喂减伤、蓄劲喂 burst,避免语义违和（⚙️ 合稿对齐）。
- 敌 **成群的那些**（← 零碎的那些·去与"碎块"撞车 + 点"量"）· **沉的那个**（← 硬的那个·"沉"覆盖重/慢/痛,不与"碎块=硬"撞)。
