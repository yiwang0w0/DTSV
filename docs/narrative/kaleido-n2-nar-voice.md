# KALEIDO · N2 NAR 声线(v2 · 失衡时代语感 + 少专名铁律)

> 2026-07-07 · 📖 剧情轨 · 取代初稿。全部小样按 N1 定稿重打:失衡时代(收缩/挂起/低频)语感 + **写作铁律**(零发明名词/日常词/句式冷而非词汇冷/不承载操作指令)。
> 世界身份:说话的是**收缩状态下的平台系统**,对象是**一台维护单位**(工程体)。系统不解释,只记录和授权;它自己也不完全知道发生了什么——这层「系统也没底」是失衡时代的独特声线资源,深界时代反而没有。
> 两种声线在游戏内**都不署名**(玩家不需要知道谁在说话——这本身是叙事钩子)。

---

## 声线 1 · 「值班的」—— 系统冷记录体(主声线 ★)

**特征**:短句;冒号与破折号;全部是可验证的行为/状态事实;词全是日常词,冷感来自句式。系统偶尔暴露「它也没有图」——失衡时代专属的不安。

| 场景 | 小样 |
|---|---|
| 开局(黑屏·只有搜索钮) | 「供电恢复。可用功能:一项。」 |
| 首次搜索 | 「翻找完毕。找到一件还能用的东西。」 |
| 首次解锁·储物 | 「你需要地方放它。——已开放:随身储物。」 |
| 首次解锁·自卫(安全上演) | 「有东西在动。它先看见了你。——已开放:自卫。」 |
| 受伤 | 「你受伤了。不重。这里不会有人来。」 |
| 过关(段间) | 「这一段,走完了。前面的图,系统里没有。」 |
| 死亡 | 「信号中断。单位登记为:失联。——记录保留。」 |
| 收敛(通关归来) | 「你回来了。走过的路,已经存进图里。门还在老地方。」 |
| 钩子(稀有·每 run ≤1) | 「本次记录多出一行。不是你写的,也不是系统写的。」 |

## 声线 2 · 「墙后的」—— 低频半人格体(稀有插入 ★)

**特征**:第二人称;只在高光时刻出现(首杀/濒死生还/走到没有图的地方);每句仍是行为叙述,不评判;它似乎比系统知道得多一点——但从不多说。

| 场景 | 小样 |
|---|---|
| 首次踏进无图区 | 「这里没有图。你还是来了。」 |
| 首杀 | 「它不动了。你还在动。记住这个差别。」 |
| 濒死生还 | 「你刚才差一点。墙后面,安静了一下。」 |
| 深处(π 揭示前) | 「再往里,名字都还没有。」 |
| 死亡(稀有替换) | 「你停下的地方,墙记得。」 |
| 通关(稀有替换) | 「走完了?那边——也看完了。」 |

## 声线 3 · 「留下的字」—— 前人残页(静态素材,不做实时 NAR)

**特征**:预写物,用预写口吻(时态诚实);出现在关卡角落/收敛页题记,不进实时日志。是「这里曾有别人」的唯一证据——**谁留下的,不说**。

| 挂载点 | 小样 |
|---|---|
| 某关角落(稀有拾取) | 「灯从第三天开始变暗。数着点用。」 |
| 搜索关氛围行 | 「东西的位置会变。我数过。」 |
| 首领关前 | 「前面那段,昨天还不在这里。」 |
| 死亡收敛页题记 | 「如果有人读到这行字——把灯留着。」 |
| 通关收敛页题记 | 「走完的人,把路留下。」 |

## 组合建议(维持 v1 结构,语感已换)

- **主声线 = 值班的**(全部常规事件,模板化,P3 NAR 实现成本最低)。
- **稀有插入 = 墙后的**(高光时刻 ≤2 条/run,稀有度即奖励)。
- **静态层 = 留下的字**(N3/N4 素材,预写口吻)。
- 三者共用日常词表,专名预算全局共享(见 N1 §3)。

## 选型项(Kanata)

1. 三声线口味如上/需调(任何一条小样语感不对,点出来我重打)。
2. 「值班的」钩子行频率:每 run ≤1(推荐)/更稀/不要。
3. 「墙后的」是否保留(若嫌玄,可全砍,纯值班的也成立——只是失衡时代的「墙后有东西」是 canon 事实,砍了可惜)。
