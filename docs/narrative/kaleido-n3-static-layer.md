## 4. 写作规范(挂载点作者手册·浓缩)

- 每条 ≤2 短句;「——」用于**叙述转折**(**不再用于系统授权**);省略号只归「墙后的」。
- **⚠ 禁宣告式(11 Diegetic UI 教义 · 长期铁律 · 取代旧「授权公告格式」)**:**不得出现「——已开放：XXX」这类系统宣告**——那等于替玩家宣布"你多了个功能",**提前剧透探索**。改为**只描述世界与动作**,把**可交互词**自然嵌进叙述——玩家没注意就是普通叙述,注意到才发现能点。可交互词单列 `action.word` 交 🎨/🔧,**nar_line 文本本身不带任何标记**(逐字可取)。现行 14 词:翻找 / 记录 / 舱里 / 状况 / 还手 / 出口 / 第一段 / 一格 / 告示 / 架势 / 拼起来 / 身上 / 掂量 / 合账。
- **可交互词选词法(六条)**:
  - ① **世界内的物件或动作**(告示/舱里/出口/合账),不用系统名词(战斗模块/储物系统/~~回合~~)。
  - ② **删除测试**:把该词从句中删掉,**句子必须不成句**——成句即证明它是贴上去的,须改。(不限语法位置,宾语/主语/谓语皆可,只认删除测试。)
  - ③ **一词一 key**:同一词不跨两个 ui_key(舱里=携带、身上=装上的强化,不混)。
  - ④ **词面唯一(作用域 = 全部玩家可见文本)**:同一**词形**不得在**任何**玩家可见位以不可点身份出现——不止别的 nar_line,还包括 `enter_text` / `description` / `ambient` / 关间横幅 / 收敛题记 / **UI 控件标签**。否则玩家学会「X 能点」后在下一处点不动,可点性的可学习性被毁。为此弃用「路」字家族(路/路数),移动改「出口」以避开「门口贴着告示」的门。**⚠ 现存跨文件撞行见 §6 清单,须随本批清理。**
  - ⑤ **四态同词**:同一 UI 在 未发现 / 常态 / 被夺走 / 临时遮蔽 四态中**必须用同一个词**指称(hp 一律「状况」);**失去态不得另起 UI 名**(如「读数」——既换词又点名 UI,双违)。
  - ⑥ **面板型用未完成态**:可交互词若指向**观测面板**而非执行按钮,句式须未完成/待办态(「够不够，还得掂量」),**不得写成已发生**(「你掂量了一下自己」会让点击沦为对既成事实的追认,抹掉发现动机)。
  - ⑦ **描述同一动作时必须避开该 key 的可交互词**(2026-07-22 · 🧭 建议立条):④ 管的是"别的地方别出现这个词",⑦ 管的是**同一件事的叙述侧**——**越是在讲那个动作本身,越容易顺手把那个词写进去**。范例:安全屋的可交互词是**「关上」**,故所有描述门闭合的句子一律写**「合上」**(「门在那儿，一直没合上」「门合上了」)。**这不是文风偏好,是可点性的可学习性**:玩家刚学会「关上」能点,下一句叙述里又出现一个不能点的「关上」,那条规律当场作废。⟹ **每个 key 定词时,同时定一个"叙述用的同义词"**,二者不得互换。
- **⚠ `inventory` = 全表唯一 auto 例外(Kanata 定)**:物品栏**自动浮现、不走点击**,故无 `action.word`、无 `hint`。理由自洽:它是**药的载体**,若走点击,发现诱饵的曲线就得跑赢它自己所保护的那个掉血时钟——**自指**。⟹ N7 亦砍掉 inventory 的"未发现态"兜底线索。**其余进度关键件全走点击**(Kanata),故 N7 §2.4 的复现诱饵是**承重结构**,不是锦上添花。
- **⚠ 隐蔽度保底(防首屏起不来)**:**当前屏上若只存在一个可行动作,该词恒为最低隐蔽度**(强提示,🎨 保底给显式可点样式)——`search_btn` 即此例:开场无任何其它 UI、玩家没有"字能点"的先验,不给提示则**第一屏无法开始**。隐蔽度渐收**只适用于玩家已掌握 ≥1 个可交互词之后**。
- **⚠ 去宣告化 ≠ 换成命令**:「顺手确认一下」「先掂量掂量」这类祈使/劝告是**操作指令**(违 N1 §3.5 双频道),是去宣告化最易踩的坑。只写**可验证的行为/状态事实**或**未完成态的处境**。
- 禁用词(玩家可见文本):纪元/文明/实验/泡层(用「泡泡」)/引导者/PI/Ω/π(π 中期揭示前禁)/残响·伪装体(名随物后,见过 3 次后才可命名)。
- 死亡文案永远登记式,不哀悼不鼓励(「信号中断。单位登记为：失联。」);情绪留给「留下的字」。
