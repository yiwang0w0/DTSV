## 主题 A — Extraction shooter 玩家挫败感

### 核心发现（5 个失败模式）

来源：[Why Do Most Extraction Shooters Fail? — games.gg](https://games.gg/news/why-most-studios-struggle-to-make-a-successful-extraction-shooter/)

1. **AAA 设计哲学冲突**：玩家追求"可访问性 + 持续进度 + 避免挫败"，但 extraction 类游戏天然需要"紧张感 + 不可预测 + 失败有代价"
2. **失败成本不够痛**：CoD DMZ 死亡只丢一把枪，没有意义 — 玩家不会"惜命"
3. **缺乏目标结构**：扔玩家进图就完事，没有 quest / lore / 长期目标
4. **泛大众化稀释难度**：核心玩家流失
5. **后期内容贫乏**：endgame 不耐玩

### 来源 2：[ARC Raiders / Tarkov 玩家社区](https://evrimagaci.org/gpt/arc-raiders-update-brings-major-changes-and-outage-533948)

- 2026-03 ARC Raiders update 1.20.0 因服务器中断引发大量玩家流失愤怒 → "稳定性 > 新内容"
- 玩家最在意：**经济系统的连贯性** + **服务器稳定** + **公平 PvP**

### 来源 3：[Steam discussion: Arena Breakout](https://steamcommunity.com/app/2073620/discussions/0/599667160179142750/)

- 玩家抱怨"extraction PvP 是从设计上就破碎的"— 装备差距碾压新手，且新手没有学习曲线缓冲
- 提议："新人专属服" 或 "PvE-only 入门期"

### DTSV 对照表

| 玩家抱怨 | DTSV 现状 | 是否已解决 |
|---|---|---|
| 装备 wipe 太频繁 | 4 类点数储备跨 raid 永不 wipe | 🟢 **已解** |
| 死亡丢全部物资 | inventory 全失，但 player_points 余额保留 + class_pt 不奖死亡 | 🟡 **部分**（仍丢本局购买的装备） |
| 失败成本不够痛 | 死亡 → 点数停止积累一局 + 时间损失 | 🟡 **平衡待校准** |
| 缺乏长期目标 | 残片解码 + class_pt 保底 + Ω 结局 | 🟢 **已解** |
| 新手墙过陡 | 无新手教程 / 无 PvE 保护期 | 🔴 **未解** |
| PvP 不平衡 | 异步探针（不是实时 PvP）+ 入场点数上限 | 🟢 **设计上规避** |
| 服务器/经济稳定性 | Phase 25 加了集中度警告 + 平衡 hint | 🟢 **基础设施已就位** |

## 主题 C — Lore-heavy 游戏叙事节奏

### 核心发现

来源 1：[Disco Elysium narrative analysis](https://warned-collectors.com/disco-elysium-narrative-structure-political-themes-and-character-customization/)

**成功点**：
- 节奏控制 = "engagement 控制"：让玩家在不同情绪强度间切换
- 对话 / 动作 / 探索三者交错
- 30+ 小时游玩 → lore-heavy 不是问题，**节奏才是**

来源 2：[LevelUpTalk - Does Disco Elysium Become Fun After 5 Hours?](https://leveluptalk.com/news/disco-elysium-fun-or-boring-review/)

**失败点**：
- 5 小时门槛：很多玩家在 "看似无事发生" 阶段弃坑
- 失败的 skill check 导致剧情停滞 → "I'm stuck on text" 焦虑
- 缺少"小胜利" 反馈（玩家需要每 30 分钟有个"我学到了什么"的明确瞬间）

来源 3：[Metacritic User Reviews](https://www.metacritic.com/game/disco-elysium-the-final-cut/user-reviews/?platform=pc)

**复合反馈**：
- "更像看书而不是玩游戏" — 双刃剑
- 喜欢的人 = 沉浸在"思考"本身的乐趣
- 不喜欢的人 = "我想 play 不想 read"

### DTSV 对照表

| 玩家诉求 | DTSV 现状 | 评估 |
|---|---|---|
| 不至于"5 小时墙" | 30 分钟一局 + 残片每局都掉新内容 | 🟢 节奏远比 Disco Elysium 友好 |
| 每 30 分钟有"我学到了什么" | 残片解码 lv1→lv2→lv3 渐进 + combo 触发 | 🟢 设计上有，但需要看实际玩家 |
| 多种反馈通道（不只读字） | 战斗 / 撤离 / 商店 / 职业 — 4 个机制并行 | 🟢 强 |
| Lore 不强加（玩家可跳过） | per-player loreInjections 过滤（24a） | 🟢 已解 |
| 失败 skill check 不卡死 | DTSV 没有 skill check 卡剧情 | 🟢 不存在该问题 |
| In-game codex（不用外置 wiki） | /archive 有但功能弱 — 没分类页 / 没"主线 vs 支线" | 🟡 **可加强** |

### 🎯 Actionable findings — C

| 优先级 | finding | 建议改动 |
|---|---|---|
| ⚡ 中 | **/archive codex 视图升级** | 加"叙事主线"标签：F01/F05→F02→...→F15 主线链可视化（已有合成图谱但没分主线/支线） |
| ⚡ 中 | **残片解码"小胜利"反馈** | 每次 lv 升级时除日志外，弹一个 toast + 短动画（强化"我学到了什么"瞬间） |
| 💡 低 | **每 raid 末显示"本局新读到"** | 结局横幅已展示 unlocksContributed，但应增加"本局新发现的残片名 + 第一句"prelude |
